# برنامج المبيعات PWA — النسخة التجريبية 0.1 (بدون مزامنة)

## النشر على GitHub Pages
1. ارفع **كل الملفات** (مسطّحة، بلا مجلدات) إلى جذر المستودع.
2. Settings ← Pages ← Deploy from branch ← main / root.
3. افتح الرابط على الهاتف في Chrome ← «تثبيت التطبيق» ← يعمل بملء الشاشة وبدون إنترنت.

## التجربة
1. أول فتح: أنشئ كلمة مرور المالك.
2. الإدارة ← إعدادات المحل، ثم «+ إضافة موظف» (بكلمة مروره)، ثم «الصلاحيات».
3. المخزون ← «لصق من Excel» لإدخال المنتجات (الرقم؛المنتج؛الشراء؛البيع؛الكمية).
4. بيع: لوحة الأرقام للبيع السريع، أو البحث وإضافة المنتجات ثم «دفع».
5. اخرج وادخل بكلمة مرور الموظف لترى صلاحياته.

## التحديث
ارفع الملفات الجديدة وغيّر الرقم في `version.js` و`version.json`؛ يتحدّث البرنامج تلقائياً ويظهر «تم تحديث البرنامج» في الشاشة الرئيسية.

## ما يعمل الآن
الدخول بالكود (المالك/الموظف)، الشاشة الرئيسية، البيع (سريع، سلة، منتج خارجي، دين، بيع بأقل من التكلفة)، المخزون، الإدارة (قيمة المحل، الإعدادات، الموظفون والصلاحيات، التصفير).
باقي البلاطات تعرض «قيد البناء». البيانات محفوظة على الجهاز (IndexedDB) ولا تُزامَن بعد.
